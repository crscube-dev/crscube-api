CTMS External API (1.1.0)

Download OpenAPI specification:

URL: https://crscube.io License: Proprietary

CRScube CTMS 의 External API 명세입니다.

수록 범위

/external/api/v1.1 로 시작하는 엔드포인트 14개입니다.

태그 개수 내용
sync 5 Site·Subject·SAE·PD/PV·SDV 동기화 (PUT)
tracker 4 SAE·PD/PV·Risk·Issue Tracker 조회
project 3 Study 조회, 스폰서 프로젝트 목록, Team 목록
mvr 2 MVR 목록, MVR 유형 코드

인증

Sync 계열(PUT 5개)은 X-API-Key 헤더가 필수입니다. 프로젝트별로 발급되며, 값은 담당자에게 문의하세요.

상태 코드를 읽는 법

이 API 는 분류되지 않은 오류까지 400 으로 응답합니다. 500 은 사실상 나오지 않습니다.

상황 실제 응답
검증 실패·본문 파싱 실패·그 밖의 오류 400
X-API-Key 누락·불일치·미설정 401 (INVALID_REQUEST)
권한 없음 403 (FORBIDDEN)
프로젝트·스터디·코드 없음 404 (RESOURCE_NOT_FOUND)

401 세 가지 사유의 errorCode 가 모두 INVALID_REQUEST 로 같습니다. 구분하려면 error.debugMessage 를 봐야 합니다.

Sync 계열에서 프로젝트를 찾지 못하면 API Key 검증보다 먼저 404 가 발생합니다.

응답 형식

성공·실패 모두 status·responseLanguage 가 항상 붙습니다.

성공  { result, message, status: "success", responseLanguage }
실패  { error: { errorCode, debugMessage, ...additional }, message,
        status: "fail", responseLanguage }

Sync(PUT) 5개는 result 가 빈 객체입니다. 처리 건수를 돌려주지 않습니다.

목록 조회 공통

  • page 는 1부터. 1 미만이면 1 로 보정됩니다.
  • size 가 서버 상한을 넘으면 오류 없이 상한값으로 보정됩니다.
  • 응답 result 에 filteredElements 로 적용된 검색 조건이 되돌아옵니다.
  • 모든 행에 deleted·no 가 붙습니다.

sync

외부 시스템 → CTMS 데이터 동기화 (PUT). X-API-Key 필수. 요청 목록은 엔드포인트마다 최대 100건이며, 감사 사유는 시스템 동기화로 기록됩니다.

Site(Team) 동기화

프로젝트의 Site(Team) 목록을 생성·갱신합니다. 한 번에 최대 100건입니다.

studyTeamKey 가 0 보다 크면 이미 동기화된 팀으로 간주합니다. 감사 사유는 시스템 동기화로 기록됩니다.

Authorizations:
externalApiKey
path Parameters
projectId
required
string
Example: SAMPLE-PROJECT

Project ID. Sync 계열(PUT)에서는 API Key 가 등록된 프로젝트를 식별하는 키이기도 합니다.

header Parameters
X-API-Key
required
string

Sync 계열(PUT) 전용 API Key.

프로젝트에 발급된 API Key 와 대조합니다.

  • 헤더가 없거나 공백이면 401 (INVALID_REQUEST, "Missing X-API-Key header")
  • 프로젝트에 API Key 가 설정되지 않았으면 401 ("API Key not configured for this study")
  • 값이 다르면 401 ("Invalid API Key")
Request Body schema: application/json
required
required
Array of objects (ExternalProjectTeamCreateRequest) <= 100 items

최대 100건. 초과 시 400.
